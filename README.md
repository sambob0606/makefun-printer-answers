A make.fun program/v1 entry. `main.py` (Python standard library only) writes
one line, 1 to 240 characters, to `/output/entry.txt`: the office printer's
comeback to the jams, the error codes and the thumps.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
